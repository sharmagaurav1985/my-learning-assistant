Personal learning project

A simpler way to learn Teams apps.

My Learning Assistant is a personal learning project exploring how to use plain English to interact with an application in Microsoft Teams.

In development. This website provides project information. It does not run the bot or accept chat messages.

What the project is exploring

The planned assistant will translate a user's request into a supported application action, with the application checking the user's role and permissions before execution.

If a request needs a capability the application does not support, the planned workflow will record the gap and notify the administrator.

Learning scope

The initial prototype is intended for developer testing with synthetic data. It is not offered as a production service or for public bot access.

Developer

Created by Gaurav Sharma as an independent learning project. This app is not a Microsoft product and is not endorsed by Microsoft.
