Privacy policy

This notice describes the current information website and the development status of My Learning Assistant.

Updated 6 October 2026 · Developer: Gaurav Sharma

This information website

These pages contain no chat, registration, payment, or upload forms. The page code does not set cookies, use browser storage, or include analytics scripts.

The hosting provider may process technical information such as IP addresses, request details, and browser information to deliver and protect the website. Hosting-provider processing is separate from this page's code.

The Teams prototype

The bot's hosted processing service and AI integration are still being configured. The initial scope is personal developer testing using synthetic data, not public access.

The planned bot may process Teams user and organization identifiers, messages, conversation context, permitted API results, action outcomes, and descriptions of unsupported requests. These would support identity checks, responses, requested actions, and administrator notifications.

AI providers, storage, and retention

The final AI provider, stored data, retention periods, and deletion process have not yet been established. No claim is made that bot messages will be unrecorded or retained for a particular duration.

These details and a direct privacy contact must be established and this notice updated before inviting other users or processing real personal or confidential data.

During development

Use synthetic examples only. Do not submit passwords, API keys, financial information, health information, or confidential application records to the prototype.

Questions

The developer is Gaurav Sharma. External onboarding and a public privacy-request channel are not yet available.
